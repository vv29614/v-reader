# 欢迎使用 V 阅读器

> 一个不联网、不登录、不做推荐的本地阅读器。文件不出你的电脑。

这份文件本身就是一个示例：它能被 V 阅读器打开，说明文本、图片、排版都正常。你可以直接在这份文件上划词、高亮、写笔记试试。

---

## 一、先试这五件事

1. 把一份 PDF 或 EPUB **直接拖进窗口**，它会被收进书架并立刻打开
2. 按 `T` 换主题，`S` 调字号和版心宽度，看文字怎么重排
3. **选中一段文字**——工具条会浮出来，点「高亮」或「笔记」
4. 笔记卡片出现后，**拖卡片**换位置（松手点 ✓），**拖右下角小三角**改大小
5. **把标签往上拖出标签栏**，右边分出一栏，同一本书两处对照

## 二、能读什么

| 类别 | 格式 | 说明 |
| --- | --- | --- |
| 电子书 | PDF / EPUB | 文本可选择可搜索、目录大纲、双页、缩放 |
| 办公文档 | DOCX | 标题、列表、表格、内嵌图片 |
| 纯文本 | Markdown / TXT / HTML / RTF | 自动识别 GBK 编码与「第 X 章」分章 |
| 漫画 | CBZ / ZIP | 按文件名排序，支持双页 |
| 数据 | CSV | 渲染成表格 |
| 代码 | 常见语言 | 语法高亮 + 行号 |
| 图片 | JPG / PNG / WebP / GIF | 缩放、旋转 |

## 三、笔记是怎么工作的

- 划词 → 工具条 → **笔记**：上半是摘录，下半写你的想法
- 保存后原文留下高亮，右侧出现一张卡片，卡片跟着文字滚动
- 卡片可以拖到任意位置、拖右下角改大小；卡片上的 `✎` 改内容，`×` 删除
- 每张卡片有一条虚线指向原文：**点线出现节点，节点都能拖**；双击线加点，双击点删点
- 窗口放不下时卡片会先收起来不挡字，侧栏（`B`）里仍然都在

## 四、AI 是可选的

不填 Key 也能正常读书、记笔记、做标签，只是没有 AI 那几样。

要用的地方：**设置 →「AI 服务（可选）」**，填接口地址、模型名、API Key（OpenAI 兼容格式，默认示例是 DeepSeek）。

能用 AI 做的事：

- 划词问：解释 / 概括 / 改写 / 术语表 / 就这段提问
- 整本书问答（会带上你正在读的章节）
- 笔记 AI：展开成一段、润色、浓缩成一句、结合正文再想
- 正文编辑：润色 / 精简 / 扩写 / 改正式 / 校对 / 续写
- 首页批量生成标签；划词生成思维导图

## 五、几个容易忽略的地方

- **快捷键都能改**：设置 →「快捷键」
- **自动滚动**：顶栏播放图标（`Ctrl+Shift+O`），运行中按 `-` / `=` 调速
- **朗读**：`R` 开始，划词工具条上的「朗读」只念选中那段
- **位置历史**：`Alt + ←/→` 像浏览器一样在跳过的位置之间来回
- **批量处理**：首页勾选多个文件，顶部出现批量条（标签 / 星标 / 在读 / 移出）
- **数据在哪**：`%APPDATA%\V阅读器\data`，整个文件夹拷走就是备份
